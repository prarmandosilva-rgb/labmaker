Quem faz o quê?

Cada ator tem seu papel claro. O sistema organiza, automatiza e apresenta.

Professor

  • Agenda aulas na Sala Maker
  • Avalia alunos por rubrica
  • Consulta dashboards pedagógicos
  • Acompanha triangulação

Aluno

  • Preenche Diário de Bordo
  • Faz autoavaliação
  • Protagonismo e reflexão
  • Documenta processo criativo

  • Gerencia inventário completo
  • Controla empréstimos
  • Monitora alertas e manutenção
  • Planeja projetos interdisciplinares

Direção / Gestão

  • Visão geral via dashboards
  • Dados para tomada de decisão
  • Justificativa para compras (TOP 10 Déficit)

Simples! O Lab Maker terá um portal próprio na web — este mesmo site — funcionando como ponto de acesso centralizado para todos:

👨‍🏫 Professor: Acessa sua área dedicada com os formulários de Agendamento de Aula e Avaliação por Rubrica, além de dashboards pedagógicos atualizados em tempo real (triangulação, desempenho por turma, projetos).

🎒 Aluno: Acessa sua área com os formulários de Diário de Bordo e Autoavaliação. Tudo pelo celular ou computador, sem instalar nada.

🏛️ Direção / Gestão: Acessa todos os dashboards — inventário, estoque, projetos, avaliações — com visão consolidada para tomada de decisão e justificativas de compra.

🔒 Segurança e Privacidade dos Dados:
✅ Ninguém edita nada pelo site — os dashboards são exibidos em modo somente leitura. Os dados originais ficam protegidos na planilha Google, acessível apenas ao coordenador Maker.
✅ Sem dados individuais expostos — os dashboards públicos mostram apenas dados agregados: médias por turma, totais por projeto, distribuição de conceitos. Nenhum nome de aluno aparece.
✅ Conformidade com a LGPD — não são coletados dados sensíveis. Os formulários pedem apenas informações pedagógicas (turma, projeto, critérios de avaliação). Não há CPF, endereço ou qualquer dado pessoal sensível.
✅ Formulários via Google Forms — os dados trafegam pela infraestrutura segura do Google Workspace, com criptografia padrão.
✅ Acesso por link — o portal funciona por navegação simples (sem login/senha), o que elimina o risco de vazamento de credenciais e simplifica o uso para todos.

Resumo: Um único endereço na web. Cada perfil encontra seus formulários e dashboards. Dados protegidos, atualizados automaticamente, sem custo. 📱➡️⚙️➡️📊
